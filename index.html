الإعدادات

إزاي أشغّلها؟

1) شغّل البرنامج على جهازك: python haram_counter.py --url "رابط البث"
2) افتح اللوحة هنا واكتب http://127.0.0.1:8765/stats ثم اضغط «اتصال».
3) المتصفح بيسمح لصفحة GitHub Pages تتصل بـ localhost في Chrome وEdge وFirefox. Safari ممكن يمنعها. لو البرنامج على سيرفر بعيد لازم رابط https (مثلاً عن طريق Cloudflare Tunnel).

الأرقام تقريبية وتعتمد على جودة الكاميرا والكشف والتتبع. اللوحة بتعرض أعداداً إجمالية فقط ولا تحفظ صوراً أو هويات.
