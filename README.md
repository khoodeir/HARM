# منظومة رصد وإحصاء الطواف

لوحة ويب (`index.html`) + خادم تحليل (`haram_counter.py`) يحسبان الطائفين والواقفين ولباس الإحرام من بث مباشر.

## التشغيل
- **الخادم** (على جهاز أو سيرفر شغّال دائماً): `start.bat` على ويندوز، أو `./start.sh` على لينكس/ماك، أو Docker بالـ `Dockerfile`.
  للسيرفر المفتوح على الشبكة: `python haram_counter.py --host 0.0.0.0 --token سر_الإدارة`
- **اللوحة**: فعّل GitHub Pages (Settings ثم Pages ثم Deploy from a branch ثم main / root).
  ضع رابط الخادم (https) في `CONFIG.servers` أعلى سكربت `index.html`، أو أضفه من قسم «الإعدادات» في اللوحة.
- **روابط البث**: تُضاف من «الإعدادات» في اللوحة (تُحفظ في `streams.json`).

الأرقام تقديرية، وتُعرض إحصاءات إجمالية فقط دون حفظ صور أو هويات.
